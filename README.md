# The Law Priest — Legal Analytics Dashboard

**Data informs, justice decides. ⚖️**

An educational legal-tech prototype for exploring case-outcome analysis, sentencing trends, and legal-text keywords in the Nigerian legal context.

## Features
- Responsive dashboard interface
- Demo case-outcome and sentencing analytics
- Legal-text keyword analysis
- Illustrative CSV case dataset
- Python FastAPI backend with SQLite storage

## Run locally
1. Install Python 3.10 or newer.
2. Install dependencies: `pip install -r requirements.txt`
3. Start the app: `uvicorn main:app --reload`
4. Open `http://127.0.0.1:8000`.

## Important limitation
This is an educational prototype. The demo predictions are rule-based, not generated by a trained machine-learning model. The included case records are illustrative, not actual Nigerian court judgments. Do not use the output to advise clients, determine sentences, or make real legal decisions.
